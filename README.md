This repository contains functionality to test the *k*-existential
transversal property (*k*-et), the stronger *k*-universal transversal
property (*k*-ut), and the even stronger strong *k*-universal transversal
property (strong *k*-ut) for a given permutation group of finite degree.

There is also a basic function for testing the *k*-id property for
groups of small degree.

Installation instructions and function documentation are contained in
the main GAP file `transversalproperties.g`.
